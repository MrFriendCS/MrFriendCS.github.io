# N5 SDD - Summer Part 1


## Task

Write a short program that will calculate the perimeter and area of a rectangle.

Use variables to store the values of the length, breadth, and the results before the answers are displayed.

Round the results to 2 decimal places.


### Example User Interface

```

-------------

7.25

19.0
units (2 dp)

16.31
units square (2 dp)

=============
```

## Testing

1. Use the values shown above.
2. Check the answers your program gives.
3. If the same, use another set of values that you know the answers to, otherwise work out what is wrong.


## Readability

Ensure that your program is easy to understand.
Use:

1. Meaningful identifiers (variable names)
2. Internal commentary (comments)
3. Whitespace (blank lines)
