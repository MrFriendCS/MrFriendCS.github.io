# N5 SDD - Create Own Task


## Task

Create a task that can be given to other pupils who have covered the SDD implementation part of the N5 CS course.

The task, and solution, must be in line with the [N5 CS specification](https://www.sqa.org.uk/sqa/files_ccc/n5-course-spec-computing-science.pdf)

The task should have three parts:

1. Create a back story, covering the purpose and any assumptions

2. Create a design - Structure diagram, Flowchart, or Pseudocode

3. Create a solution

Make sure all 3 parts 'hang together'.


## Links

The back story can be formatted in Markdown, but it is not a requirement.
Diagrams can be hand drawn.
