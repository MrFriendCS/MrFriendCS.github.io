# N5 SDD - Wireframe


## Introduction

Some pupils need a bit of extra support when doing maths.
Unfortunately, the calculators in the maths department have have too many features, which leads to confusion.
It is hoped that a simple app can be created that will allow pupils to quickly check their answers.


## Task

Create a wireframe for a simple calculator app that will only add, subtract, multiply or divide two numbers.

Use [draw.io](https://app.diagrams.net/) to create the wireframe.
The wireframe will then be used to see if it meets the expectations of the maths department.

Annotate the wireframe with where the pupils will enter the values and see the results.
