# N5 SDD - Result Part 4


## Introduction

A user wants an automatic grading system that will classify a test score using the table below.

| Mark    | Grade |
| ----    | :---: |
| 70+     | A |
| 60 - 69 | B |
| 50 - 59 | C |
| 40 - 49 | D |
| 0 - 39  | No Award |
